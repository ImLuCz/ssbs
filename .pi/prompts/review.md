description: Weekly triage — sweep inbox, roll over tasks, flag stale projects
---
Run a full review of the second brain:

1. Go through every item in INBOX.md and sort it into projects/, knowledge/,
   ideas/, or TODO.md as appropriate. Clear INBOX.md once done.
2. Check TODO.md's `## Today` section for unchecked items. Roll them over into
   today explicitly (list them out loud to me) rather than silently carrying
   them forward.
3. Look at git log timestamps for files in projects/ — flag any project file
   with no changes in the last 7+ days as possibly stale.
4. For each file in ideas/ older than 2 weeks, ask me whether it should move to
   `## Someday` in TODO.md, get archived, or stay as-is.
5. Give me a short summary of what changed.
