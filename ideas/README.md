# Ideas

One dated file per idea: `YYYY-MM-DD-short-topic.md`.

Created automatically when you say something like "that's interesting, I'll look
into it," or manually via `/idea <topic>`. Each file should capture: what the idea
is, why it came up (link back to the project/knowledge file if relevant), and any
initial thoughts. Doesn't need to be polished — this is a parking lot, not a report.

Reviewed during `/review`: stale ideas get moved to `## Someday` in `TODO.md` or
deleted if they no longer seem worth pursuing.
