# Projects

One file per active project: `project-name.md`.

Each file should have: what the project is, current status, what's left to do,
and links to related `knowledge/` and `ideas/` files. Updated by the agent
whenever we discuss the project in conversation — you don't need to update these
by hand.

When a project is done, it gets `git mv`'d to `archive/projects/`, not deleted.
